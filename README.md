# Survey for website-making service

This is the final project for the Kiwi class at Code The Dream.
It is a React single-page application that lets users submit a website request form. Submitted
data is persisted locally using browser Local Storage by default.

## Dependencies

- react
- react-dom
- react-router and react-router-dom
- vite

This project uses CSS Modules for styling and small shared components. It does not require
styled-components by default.

## Installation

Clone and install

Windows PowerShell (recommended):

```powershell
# clone the repo (run once)
git clone <repository-url> ; cd <repository-folder>

# install dependencies
npm install
```

Cross-platform (macOS / Linux / WSL / PowerShell):

```bash
# clone the repo (run once)
git clone <repository-url>
cd <repository-folder>

# install dependencies
npm install
```

Run the app

Development server (hot reload):

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
